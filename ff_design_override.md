# FluxFoxus (FF) Design System Override

## Core Palette (Rustic Medley)
This palette strictly overrides the default FF design system (Midnight Slate / Electric Indigo). All UI rendering, Stitch generation, and Tailwind/CSS styling MUST map to these exact hex codes:

*   **color_background:** `#13191F` (River Styx) — Replaces Midnight Slate (#0F172A)[cite: 1, 27].
*   **color_surface:** `#2B2F2E` (Carbon Fibre) — Replaces Slate Blue (#1E293B)[cite: 1, 27].
*   **color_border:** `#594C3D` (Afternoon Tea) — Replaces rgba(148,163,184,0.1) for card borders and dividers[cite: 1, 27].
*   **color_accent:** `#906D4B` (Tanned Wood) — Replaces Soft Cyan (#22D3EE) for secondary UI elements, timer display in breaks, and sub-labels[cite: 1, 27].
*   **color_primary:** `#CA9C68` (Amber Autumn) — Replaces Electric Indigo (#6366F1) for primary actions, start/stop buttons, active states, and the flip-clock mechanical split line[cite: 1, 27].

## Text & Legibility Rules
*   **color_text_primary:** `#F8FAFC` (Ghost White) — Retained for high contrast against `#13191F`[cite: 27].
*   **color_text_muted:** `#94A3B8` — Retained for disabled buttons and secondary captions[cite: 27].
*   No purples, blues, or cyans from the original spec should be generated by the AI[cite: 1, 27].
