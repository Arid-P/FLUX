## 🎯 Architectural Overview: FluxDone (FD)

- **Role:** High-performance, offline-first task and habit manager replacing **TickTick** in Ari's academic workflow.
- **Core Principles:** Calendar timeline tapping as primary creation surface, strict duration preservation, live markdown notes, 4-tier hierarchy (Folders → Lists → Sections → Tasks), and zero bloat.
- **Technology Stack:** Native Android Kotlin + Jetpack Compose (API 26–34) + Compose Multiplatform for Ubuntu Linux Desktop + Room SQLite (KSP) + MVI Architecture.
